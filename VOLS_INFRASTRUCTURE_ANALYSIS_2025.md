## 1. Введение и контекст

### 1.1 О ГАУ ТО ТРТЦ

ГАУ ТО ТРТЦ (Тюменский региональный телекоммуникационный центр) — региональный инфраструктурный оператор, обеспечивающий:

- **Управление региональной сетью ВОЛС** Тюменской области
- **Подключение социально значимых объектов** (школы, больницы, администрации)
- **Реализацию программы "Устранение цифрового неравенства"**
- **Обеспечение связи** для органов государственной власти
- **Развитие телекоммуникационной инфраструктуры** региона

### 1.2 Основные требования к системе учета ВОЛС

| Требование | Приоритет | Описание |
|------------|-----------|----------|
| **Локальное развертывание** | Критический | Работа на собственных серверах без зависимости от облака |
| **Геопространственное отображение** | Высокий | Визуализация маршрутов ВОЛС на карте региона |
| **Учет волокон и оборудования** | Высокий | Детальный учет всех элементов сети |
| **Интеграция с ГИС** | Средний | Экспорт/импорт данных в стандартных форматах |
| **Русскоязычный интерфейс** | Критический | Полная локализация |
| **Импортозамещение** | Высокий | Соответствие требованиям законодательства РФ |
| **Экономическая эффективность** | Высокий | Минимизация совокупной стоимости владения |

### 1.3 Особенности Тюменской области

- **Площадь**: 1 435 200 км² (крупнейший регион России)
- **Протяженность ВОЛС**: тысячи километров
- **Климатические условия**: от -50°C до +35°C
- **Специфика**: большие расстояния между населенными пунктами
- **Задачи**: обеспечение связности отдаленных территорий

### 7.3 Модель данных ВОЛС

```sql
-- Основные сущности системы учета ВОЛС

-- 1. Узлы связи (муфты, кроссы, БСП, терминалы)
nodes (id, name, type, coordinates, address, status, metadata)

-- 2. ВОЛС маршруты (кабельные трассы)
vols (id, name, start_node, end_node, path_geometry, length_km, cable_type, status)

-- 3. Волокна (отдельные волокна в кабеле)
fibers (id, vols_id, fiber_number, color, status, assigned_to)

-- 4. Связи (логические соединения)
links (id, fiber_id, start_node, end_node, bandwidth, status)

-- 5. Карты/Проекты
webmaps (id, name, layers, center, zoom, permissions)

-- 6. Пользователи
users (id, username, email, password_hash, role)
```
