# 🏋️ Личный тренер - Telegram Bot

Профессиональный русскоязычный Telegram-бот для отслеживания питания, тренировок и прогресса похудения.

## 📱 Telegram

**Бот:** [@mytrener1_bot](https://t.me/mytrener1_bot)

## ✨ Возможности

### 🍽️ Дневник питания
- Поиск продуктов из базы данных (60+ продуктов)
- Добавление своих продуктов
- Подсчет калорий и БЖУ
- История приемов пищи по дням
- Отслеживание прогресса к целям

### 💧 Трекер воды
- Быстрое добавление воды (100-500мл)
- Расчет индивидуальной нормы
- Визуальный прогресс-бар
- Отмена последней записи

### ⚖️ Трекер веса
- Запись веса
- История изменений
- Текстовые графики прогресса
- Расчет BMI

### 📊 Статистика
- Дневная статистика с прогресс-барами
- Недельные отчеты
- Средние показатели
- Отслеживание достижений

### 👤 Персонализация
- Расчет BMR и TDEE
- Индивидуальные нормы КБЖУ
- Выбор цели (похудение/набор/поддержание)
- Учет уровня активности

### 🎮 Геймификация
- Система XP и уровней
- Серии (streaks) активности
- Достижения
- Мотивационные награды

## 🚀 Быстрый старт

### Требования
- Python 3.11+
- pip

### Установка

```bash
# Клонировать репозиторий
git clone <repository-url>
cd fitness-bot

# Создать виртуальное окружение
python -m venv venv
source venv/bin/activate  # Linux/macOS
# или
venv\Scripts\activate  # Windows

# Установить зависимости
pip install -r requirements.txt
```

### Настройка

1. Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

2. Укажите токен бота в `.env`:

```env
BOT_TOKEN=your_bot_token_here
```

### Запуск

```bash
python -m bot.main
```

## 📐 Формулы расчета

### BMR (Базовый метаболизм) - Mifflin-St Jeor

```
Мужчины: BMR = 10 × вес(кг) + 6.25 × рост(см) − 5 × возраст + 5
Женщины: BMR = 10 × вес(кг) + 6.25 × рост(см) − 5 × возраст − 161
```

### TDEE (Суточный расход)

```
TDEE = BMR × Коэффициент активности

Коэффициенты:
- Минимальная: 1.2
- Низкая: 1.375
- Средняя: 1.55
- Высокая: 1.725
- Очень высокая: 1.9
```

### Целевые калории

```
Похудение: TDEE - 500 ккал
Поддержание: TDEE
Набор массы: TDEE + 500 ккал
```

### BMI (Индекс массы тела)

```
BMI = вес(кг) / рост(м)²

< 18.5  - Недостаточный вес
18.5-25 - Норма
25-30   - Избыточный вес
> 30    - Ожирение
```
