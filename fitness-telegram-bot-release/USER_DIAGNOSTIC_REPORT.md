## 🔴 КРИТИЧЕСКИЕ ПРОБЛЕМЫ (Blockers)

### BUG-C01: Команда /quick_food не реализована
**Приоритет:** 🔴 КРИТИЧЕСКИЙ  
**Воспроизведение:**
1. Отправить /help
2. Увидеть в списке `/quick_food`
3. Отправить `/quick_food`
4. **Результат:** Бот молчит, команда не работает

**Влияние:** Пользователь теряет доверие к боту. Обещанная функция не работает.

**Файл:** `bot/handlers/start.py` (help упоминает), реализации нет

### BUG-C05: Напоминания настраиваются, но НЕ ОТПРАВЛЯЮТСЯ
**Приоритет:** 🔴 КРИТИЧЕСКИЙ  
**Воспроизведение:**
1. Перейти в ⏰ Напоминания
2. Включить напоминание на текущее время
3. Подождать указанное время
4. **Результат:** Напоминание не приходит

**Причина:** Отсутствует фоновый worker для отправки напоминаний

**Влияние:** Пользователь теряет главную мотивационную функцию. Доверие к боту подорвано.

## 🟠 СЕРЬЁЗНЫЕ ПРОБЛЕМЫ (Major)

### BUG-M01: Нет валидации целевого веса относительно цели
**Приоритет:** 🟠 ВЫСОКИЙ  
**Воспроизведение:**
1. Начать онбординг
2. Текущий вес: 80 кг
3. Цель: "Похудеть"
4. Целевой вес: 90 кг ← ПРИНИМАЕТСЯ!

**Влияние:** Логическое противоречие. Расчёты будут некорректными.

---

### BUG-M02: Часовой пояс не используется
**Приоритет:** 🟠 ВЫСОКИЙ  
**Воспроизведение:**
1. Перейти в ⚙️ Настройки
2. Показывается "🌍 Часовой пояс: Europe/Moscow"
3. Все операции с датами используют серверное время

**Влияние:** Для пользователей в других часовых поясах статистика за "сегодня" будет неправильной.

---

### BUG-M03: Нельзя изменить время напоминания
**Приоритет:** 🟠 ВЫСОКИЙ  
**Воспроизведение:**
1. Открыть ⏰ Напоминания
2. Можно только вкл/выкл
3. Нет кнопки изменения времени

**Влияние:** Пользователь не может настроить напоминания под свой график
