# 🎯 Руководство по работе с проектом в Cursor

Это руководство поможет вам доработать и расширить бота "Личный Тренер" с помощью Cursor AI.

## 🚀 Начало работы

### Шаг 1: Откройте проект в Cursor

```bash
# Если Cursor установлен
cursor /путь/к/personal-trainer-bot
```

### Шаг 2: Настройте окружение

1. Откройте терминал в Cursor (`Ctrl+`` или `Cmd+``)
2. Создайте виртуальное окружение:

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate     # Windows
pip install -r requirements.txt
```

### Шаг 3: Настройте .env

```bash
cp .env.example .env
```

Отредактируйте `.env` и добавьте токен бота.

## 🔧 Частые задачи

### Изменение текстов сообщений

Все тексты находятся в хендлерах (`bot/handlers/`). Чтобы изменить:

1. Найдите нужный хендлер
2. Измените строку сообщения
3. Используйте Markdown для форматирования

### Добавление новой команды

1. Создайте хендлер:
```python
@router.message(Command("mycommand"))
async def cmd_mycommand(message: Message, session: AsyncSession):
    await message.answer("Ответ на команду")
```

2. Зарегистрируйте в роутере

### Изменение клавиатур

Все клавиатуры в `bot/keyboards/inline.py`. Пример:

```python
def get_my_keyboard() -> InlineKeyboardMarkup:
    builder = InlineKeyboardBuilder()
    builder.row(
        InlineKeyboardButton(text="Кнопка", callback_data="my_callback")
    )
    return builder.as_markup()
```

### Добавление новой таблицы в БД

1. Создайте модель в `database/models/`
2. Импортируйте в `database/models/__init__.py`
3. Перезапустите бота — таблица создастся автоматически

## 🚀 Деплой

### На VPS/сервере

```bash

# 2. Настроить окружение

```

## ❓ FAQ

**Q: Бот не отвечает**
A: Проверьте токен в `.env` и логи

**Q: Не работает ИИ-генерация**
A: Добавьте `OPENAI_API_KEY` в `.env`

**Q: Как сбросить БД?**
A: Удалите файл `database/trainer.db` и перезапустите бота

**Q: Как добавить несколько языков?**
A: Используйте библиотеку `aiogram-i18n` и создайте файлы переводов
